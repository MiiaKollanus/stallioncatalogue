# Stallion Catalogue
Stallion catalogue for Virtual World Championships 2025

## How to use the stallion catalogue ##

- Use the A–Z links at the top to jump to stallions whose breed begin with that letter.
- You can also use the search bar, just type a stallion’s name or breed.
- Use the email or another contact method shown under each horse if you want to reach out.
- Note: We cannot guarantee that every information is correct on this page. Please always check the correct information from the stallion's site. 
- If you see any totally incorrect information (for example the breed is wrong), please contact us asap. The fastest way to contact is through Dimma: dimmavirtuaali@gmail.com
